# AX 코칭 플랫폼

창작자가 좋은 프롬프트를 쓰지 못해도, 과제별 적응형 질문으로 아이디어를 구체화해 사업계획·상품기획·브랜딩·마케팅 콘텐츠 결과물로 바꾸도록 돕는 모바일 친화형 AI 코칭 플랫폼입니다.

- 백엔드: FastAPI (과제별 하네스 + 교체 가능한 LLM Provider)
- 프론트엔드: React + Vite + TypeScript
- 설계 문서: [`docs/superpowers/specs/`](docs/superpowers/specs/)
- 구현 계획: [`docs/superpowers/plans/`](docs/superpowers/plans/)
