창작자 AX · 최종 UX 개선안

실행 방법
1. ZIP 파일을 다운로드하고 압축을 모두 풀어 주세요.
2. AX_Studio_UX_V2 폴더 안의 index.html을 더블 클릭해 주세요.
3. 브라우저가 아닌 다른 앱으로 열리면, 파일을 우클릭 → 연결 프로그램에서 Chrome, Edge 또는 Safari를 선택해 주세요.

별도 설치나 로그인이 필요하지 않습니다.
PC 화면을 기준으로 제작했습니다. 폰트와 아이콘은 HTML 안에 포함되어 있습니다.
메일이나 메신저의 파일 미리보기 대신, 다운로드한 파일을 브라우저에서 열어 주세요.
화면은 오프라인에서도 실행할 수 있으며, 외부 참고 자료 원문을 열 때만 인터넷 연결이 필요합니다.

체험 순서
과제 선택 → 요청 입력 → 코칭 모드 선택 → 질문 답변 → 초안 확인
→ 미확인 정보 입력·저장 → 초안에 반영 → 문구 수정·근거 검토 → 버전 저장
저장한 버전은 왼쪽 '결과물'에서 다시 열 수 있습니다.

알아두세요
- 실제 AI 서버에 연결되지 않은 예시 기반 LF 프로토타입입니다.
- 입력 내용과 저장한 버전은 각 사용자의 브라우저에 보관됩니다.
- 이 ZIP에는 기존 사용자의 입력 내용이나 저장 기록이 포함되지 않습니다.
- 다른 기기나 다른 사람과 입력 내용이 자동으로 동기화되지 않습니다.
- 브라우저의 저장 제한이나 데이터 삭제로 기록이 사라질 수 있으므로, 필요한 결과는 '문서 내려받기'로 보관해 주세요.
- 파일을 다른 경로로 옮기면 이전 브라우저 저장 내용이 보이지 않을 수 있습니다.

공유 방법
이 ZIP 파일을 그대로 전달해 주세요. 받는 사람도 위 순서대로 실행하면 됩니다.

소융님 피드백 반영
- 모든 질문에 다른 예시 보기 / 원래 예시 보기 추가
- 코칭 모드 설명에서 고정 질문 수 삭제
- 결과 문서에 이미지 배치 예시 블록 추가 (실제 이미지 생성 기능 아님)
- 생성 중·생성 실패·결과가 최신이 아님 상태 추가
- 요청이나 답변 변경 시 기존 결과를 유지하고 다시 생성하도록 안내

상태 화면 확인
왼쪽 이용 안내에서 생성 중 보기, 생성 실패 체험, 최신이 아님 보기를 선택할 수 있습니다.
실패 상태는 검토용 시뮬레이션입니다.
390px 반응형 스타일을 포함하며, 실제 모바일 브라우저의 시각 검수는 별도로 필요합니다.
