# 디자인 V2 묶음 1 (질문 흐름 화면) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 디자인 V2의 홈 → 요청 → 코칭 모드 → 질문(흐름 패널) → 답변 확인 → 결과 문서(텍스트) 흐름을 실제 백엔드와 함께 동작시킨다. 백엔드에는 답변 종류 정리('다른 예시 보기'·'아직 모르겠어요'·'원래 예시 보기'), 흐름 패널용 질문 목록(`flow`), 익명 사용자(owner)를 더한다.

**Architecture:** 백엔드는 지금 구조(얇은 라우터 → 하네스 → 순수 뷰 함수)를 그대로 따른다. 프론트는 해시 주소(`lib/routes.ts`) + `useReducer` 하나(`app/state.ts`)로 상태를 바꾸고, 그릴 화면은 순수 함수 `screenModel`이, 모자란 데이터는 `needsLoad`가 정한다. 화면(`screens/`)과 부품(`components/`)은 props만 받고, 앱과 미리보기 갤러리가 같은 `AppView`로 그린다.

**Tech Stack:** FastAPI · Pydantic v2 · pytest (백엔드, `uv`), React 19 · Vite 8 · TypeScript 5.9 · vitest 5 · openapi-fetch · openapi-typescript (프론트)

## 설계 문서와 다르게 정한 것 (컨트롤러 결정)

1. **모드 화면은 세션 전 주소(`#/{task}/mode`)다.** 모드는 세션을 만들 때 정해지고(`CreateSessionRequest.mode`) 진단과 첫 질문도 그때 돈다. 요청 글은 브라우저에 초안으로 두고, 모드를 고르는 순간 세션을 만든다. 설계의 `#/s/{id}/mode`는 쓰지 않는다.
2. **`FlowItem`은 `question_id` 대신 `question`(질문 전체 또는 null)을 싣는다.** 답을 고칠 때 그 질문의 선택지를 다시 보여 줘야 해서다.
3. **`plan_flow(policy, state, remaining)`** — 세 번째 인자는 상한(cap)이 아니라 하네스가 아직 더 물을 수 있는 기본 질문 수(`BaseHarness.questions_left`)다. 멈출 때가 된 세션에 '예정'이 남아 보이지 않게 한다.
4. **질문 상한은 기본 질문(level 0)에 답한 필드 수로 센다(같은 필드는 한 번).** '원래 예시 보기'로 같은 기본 질문을 다시 받아도 두 번 세지 않는다. 지금까지는 필드마다 기본 질문 기록이 하나뿐이라 결과가 같다.
5. **홈의 "이어하기"와 "내 작업 보기", 왼쪽 메뉴의 내 작업·결과물은 묶음 2(`GET /sessions`)에서 연다.**
6. **늦게 온 응답**: 리듀서는 지금 기다리는 요청 번호(`inflight.seq`)의 응답만 받는다. 과제·세션 묶음(`contextOf`)을 떠나는 이동은 기다리던 요청을 버린다(묶음 0 PR에서 넘긴 요구).

```python
def counted_fields(records: Sequence[AskedQuestion]) -> set[str]:
    """[코드·순수] 질문 상한에 센 필드: 기본 질문(level 0)에 한 번이라도 답한 필드.

    사다리 재질문(level ≥ 1)과 지금 걸려 있는 질문은 세지 않는다. '원래 예시 보기'로 같은 기본 질문을
    다시 받아도 필드 하나로 센다.
    """
    return {r.question.field for r in records if r.question.level == 0 and r.answer_type is not None}
```

```python
        field = self.policy.field(question.field)

            self._drop_unanswered(state)
            state.easier_levels.pop(field.name, None)
            self._pose(state, self.base_question(state, field))
            _settle_status(state)
```

```python
"""흐름 패널(질문과 답변 흐름)의 질문 목록. 세션 상태와 정책에서 만드는 순수 함수다."""
from collections.abc import Sequence
from enum import StrEnum

from app.core.contract import ContractModel
from app.core.state import AnswerType, AskedQuestion, Question, SessionState
from app.harness.base import counted_fields, unresolved_fields
from app.harness.policy import FieldPolicy, TaskPolicy


class FlowStatus(StrEnum):
    ANSWERED = "answered"  # 값을 정했다
    CURRENT = "current"  # 지금 걸려 있는 질문
    UPCOMING = "upcoming"  # 앞으로 물을 예정(정책 순서, 남은 질문 수만큼)
    SKIPPED = "skipped"  # '아직 모르겠어요'로 미정


class FlowItem(ContractModel):
    field: str
    label: str
    text: str
    status: FlowStatus
    answer: str | None  # 정한 값. 현재·예정·미정이면 None
    # 현재 질문이거나 답한(미정 포함) 질문. 이 질문의 question_id로 답을 고친다(PATCH). 예정이면 None
    question: Question | None


_VALUE_ANSWERS = (AnswerType.OPTION, AnswerType.FREE_TEXT)


def plan_flow(policy: TaskPolicy, state: SessionState, remaining: int) -> list[FlowItem]:
    """[순수] 물어본 필드(처음 물은 순서) → 지금 질문 → 앞으로 물을 필드(정책 순서).

    remaining은 하네스가 아직 더 물을 수 있는 기본 질문 수다(BaseHarness.questions_left). 지금 질문이 아직
    상한에 세지 않은 필드면 그 한 자리를 쓴다. 정책에 없는 필드(정책이 바뀌어 사라진 필드)는 건너뛴다.
    """
    fields = {f.name: f for f in policy.fields}
    pending = state.pending_question
    current = pending.field if pending is not None else None
    items = [
        _asked_item(fields[name], state)
        for name in _asked_order(state.asked_questions)
        if name != current and name in fields and (name in state.facts or name in state.unknowns)
    ]
    if pending is not None and pending.field in fields:
        items.append(
            FlowItem(
                field=pending.field,
                label=fields[pending.field].label,
                text=pending.text,
                status=FlowStatus.CURRENT,
                answer=None,
                question=pending,
            )
        )
    uncounted_current = pending is not None and pending.field not in counted_fields(state.asked_questions)
    slots = max(remaining - (1 if uncounted_current else 0), 0)
    waiting = [f for f in unresolved_fields(policy.fields, state.facts, state.unknowns) if f.name != current]
    items.extend(_upcoming_item(f) for f in waiting[:slots])
    return items


def _asked_order(records: Sequence[AskedQuestion]) -> list[str]:
    """답한 기록이 있는 필드를 처음 답한 순서로."""
    order: list[str] = []
    for record in records:
        if record.answer_type is not None and record.question.field not in order:
            order.append(record.question.field)
    return order


def _asked_item(field: FieldPolicy, state: SessionState) -> FlowItem:
    """답한 필드 하나. 값이 있으면 그 값을 정한 질문, 미정이면 미정으로 둔 질문을 싣는다."""
    records = [
        r for r in state.asked_questions if r.question.field == field.name and r.answer_type is not None
    ]
    if field.name in state.facts:
        holder = next(
            (r for r in reversed(records) if r.answer_type in _VALUE_ANSWERS and not r.superseded), records[-1]
        )
        return FlowItem(
            field=field.name,
            label=field.label,
            text=holder.question.text,
            status=FlowStatus.ANSWERED,
            answer=state.facts[field.name].value,
            question=holder.question,
        )
    holder = next((r for r in reversed(records) if r.answer_type is AnswerType.SKIP), records[-1])
    return FlowItem(
        field=field.name,
        label=field.label,
        text=holder.question.text,
        status=FlowStatus.SKIPPED,
        answer=None,
        question=holder.question,
    )


def _upcoming_item(field: FieldPolicy) -> FlowItem:
    return FlowItem(
        field=field.name,
        label=field.label,
        text=field.question,
        status=FlowStatus.UPCOMING,
        answer=None,
        question=None,
    )
```

```ts
import type { KeyValueStore } from "./storage";

export const CLIENT_ID_KEY = "ax.client-id";
const CLIENT_ID = /^[A-Za-z0-9-]{8,64}$/; // 백엔드 app/api/owner.py와 같은 형식

export function isClientId(value: string): boolean {
  return CLIENT_ID.test(value);
}

/**
 * 이 브라우저의 익명 사용자 ID. 저장해 둔 값이 있으면 쓰고, 없거나 형식이 틀리면 새로 만들어 저장한다.
 * 저장소를 못 쓰면 이번 실행에서만 쓰는 ID가 된다(새로 고치면 다른 사용자로 보인다).
 */
export function loadClientId(storage: KeyValueStore | null, makeId: () => string): string {
  const saved = readSaved(storage);
  if (saved !== null && isClientId(saved)) return saved;
  const id = makeId();
  try {
    storage?.setItem(CLIENT_ID_KEY, id);
  } catch {
    // 저장하지 못해도 이번 실행에서는 쓴다
  }
  return id;
}

function readSaved(storage: KeyValueStore | null): string | null {
  try {
    return storage?.getItem(CLIENT_ID_KEY) ?? null;
  } catch {
    return null;
  }
}

type RandomSource = Pick<Crypto, "getRandomValues"> & Partial<Pick<Crypto, "randomUUID">>;

/** 새 ID. randomUUID는 보안 컨텍스트(https·localhost)에서만 있어 없으면 무작위 바이트로 만든다. */
export function makeClientId(source: RandomSource = crypto): string {
  if (source.randomUUID) return source.randomUUID();
  const bytes = source.getRandomValues(new Uint8Array(16));
  return Array.from(bytes, (b) => b.toString(16).padStart(2, "0")).join("");
}
```

```ts
/**
 * 화면 주소(해시). 주소를 읽고 만드는 곳은 parseRoute·toHash 두 함수뿐이다.
 * 과제 화면(요청·모드)은 세션 전이라 과제 이름으로, 세션 화면은 세션 id로 연다.
 */
export type Route =
  | { name: "home" }
  | { name: "guide" }
  | { name: "request"; task: string }
  | { name: "mode"; task: string }
  | { name: "question"; sessionId: string }
  | { name: "revise"; sessionId: string; questionId: string }
  | { name: "confirm"; sessionId: string }
  | { name: "result"; sessionId: string };

export const HOME: Route = { name: "home" };

const TASK_VIEWS = new Set(["request", "mode"]);
const SESSION_VIEWS = new Set(["question", "confirm", "result"]);

function decode(segment: string): string {
  try {
    return decodeURIComponent(segment);
  } catch {
    return segment;
  }
}

/** [순수] 해시를 주소로. 모르는 모양은 홈이다. */
export function parseRoute(hash: string): Route {
  const parts = hash.replace(/^#\/?/, "").split("/").filter(Boolean).map(decode);
  const [first, second, third, fourth] = parts;
  if (parts.length === 1 && first === "guide") return { name: "guide" };
  if (parts.length === 2 && first !== "s" && TASK_VIEWS.has(second)) {
    return second === "request" ? { name: "request", task: first } : { name: "mode", task: first };
  }
  if (first === "s" && parts.length === 3 && SESSION_VIEWS.has(third)) {
    if (third === "question") return { name: "question", sessionId: second };
    return third === "confirm" ? { name: "confirm", sessionId: second } : { name: "result", sessionId: second };
  }
  if (first === "s" && parts.length === 4 && third === "question") {
    return { name: "revise", sessionId: second, questionId: fourth };
  }
  return HOME;
}

/** [순수] 주소를 해시로. */
export function toHash(route: Route): string {
  const e = encodeURIComponent;
  switch (route.name) {
    case "home":
      return "#/";
    case "guide":
      return "#/guide";
    case "request":
    case "mode":
      return `#/${e(route.task)}/${route.name}`;
    case "revise":
      return `#/s/${e(route.sessionId)}/question/${e(route.questionId)}`;
    default:
      return `#/s/${e(route.sessionId)}/${route.name}`;
  }
}

/** [순수] 화면 묶음. 같은 묶음 안에서 옮기면 기다리던 요청을 그대로 받고, 묶음을 떠나면 늦은 응답을 버린다. */
export function contextOf(route: Route): string {
  switch (route.name) {
    case "home":
    case "guide":
      return route.name;
    case "request":
    case "mode":
      return `task:${route.task}`;
    default:
      return `session:${route.sessionId}`;
  }
}

export function taskOf(route: Route): string | null {
  return route.name === "request" || route.name === "mode" ? route.task : null;
}

export function sessionIdOf(route: Route): string | null {
  return "sessionId" in route ? route.sessionId : null;
}
```

```ts
import type { ResultView, SessionView, TaskForm, TaskSummary } from "../api/types";
import { contextOf, sessionIdOf, taskOf, toHash } from "../lib/routes";
import type { Route } from "../lib/routes";

/** 기다리는 요청. seq가 다른 응답은 늦게 온 것이라 버린다. load는 화면을 그리려고 부른 요청의 이름(loadKey)이다. */
export type Inflight = { seq: number; load: string | null };

export type AppState = {
  route: Route;
  tasks: TaskSummary[];
  form: TaskForm | null; // 지금 과제의 입력 양식(요청·모드 화면)
  session: SessionView | null;
  sessionOutdated: boolean; // 결과를 만들었거나 생성이 실패해 서버 세션이 바뀌었다. 다시 받아야 한다
  result: ResultView | null;
  drafts: Record<string, string>; // 과제별 쓰다 만 요청 글
  inflight: Inflight | null;
  stalled: string | null; // 실패한 불러오기(loadKey). 같은 화면에서는 다시 부르지 않는다
  toast: string | null;
};

export type Action =
  | { type: "navigated"; route: Route }
  | { type: "requested"; seq: number; load: string | null }
  | { type: "failed"; seq: number; message: string; outdatesSession: boolean }
  | { type: "tasksLoaded"; seq: number; tasks: TaskSummary[] }
  | { type: "formLoaded"; seq: number; form: TaskForm }
  | { type: "sessionLoaded"; seq: number; session: SessionView; next: Route | null; notice: string | null }
  | { type: "resultLoaded"; seq: number; result: ResultView; next: Route | null; outdatesSession: boolean }
  | { type: "draftChanged"; task: string; text: string }
  | { type: "noticed"; message: string }
  | { type: "toastClosed" }
  | { type: "retried" };

type Settled = Exclude<Extract<Action, { seq: number }>, { type: "requested" }>;

export function initialState(route: Route): AppState {
  return {
    route,
    tasks: [],
    form: null,
    session: null,
    sessionOutdated: false,
    result: null,
    drafts: {},
    inflight: null,
    stalled: null,
    toast: null,
  };
}

export function isBusy(state: AppState): boolean {
  return state.inflight !== null;
}

/** 앱 상태는 여기서만 바뀐다(순수). 응답은 지금 기다리는 요청(inflight.seq)의 것일 때만 받는다. */
export function reducer(state: AppState, action: Action): AppState {
  switch (action.type) {
    case "navigated":
      return navigate(state, action.route);
    case "requested":
      return { ...state, inflight: { seq: action.seq, load: action.load }, toast: null };
    case "draftChanged":
      return { ...state, drafts: { ...state.drafts, [action.task]: action.text } };
    case "noticed":
      return { ...state, toast: action.message };
    case "toastClosed":
      return { ...state, toast: null };
    case "retried":
      return { ...state, stalled: null };
    default: {
      const inflight = state.inflight;
      if (inflight === null || inflight.seq !== action.seq) return state;
      return settle({ ...state, inflight: null }, inflight, action);
    }
  }
}

/** 화면 이동. 과제·세션 묶음(contextOf)을 떠나면 기다리던 요청의 응답을 버리고, 다른 과제·세션의 데이터는 비운다. */
function navigate(state: AppState, route: Route): AppState {
  if (toHash(route) === toHash(state.route)) return state;
  const sessionId = sessionIdOf(route);
  const sameSession = state.session !== null && state.session.session_id === sessionId;
  return {
    ...state,
    route,
    inflight: contextOf(route) === contextOf(state.route) ? state.inflight : null,
    stalled: null,
    form: state.form !== null && state.form.task_type === taskOf(route) ? state.form : null,
    session: sameSession ? state.session : null,
    sessionOutdated: sameSession && state.sessionOutdated,
    result: state.result !== null && state.result.session_id === sessionId ? state.result : null,
  };
}

function settle(done: AppState, inflight: Inflight, action: Settled): AppState {
  switch (action.type) {
    case "failed":
      return {
        ...done,
        toast: action.message,
        stalled: inflight.load ?? done.stalled,
        sessionOutdated: done.sessionOutdated || action.outdatesSession,
      };
    case "tasksLoaded":
      return { ...done, tasks: action.tasks };
    case "formLoaded":
      return { ...done, form: action.form };
    case "sessionLoaded":
      return {
        ...done,
        route: action.next ?? done.route,
        session: action.session,
        sessionOutdated: false,
        result: matchingResult(done.result, action.session),
        toast: action.notice ?? done.toast,
      };
    case "resultLoaded":
      return {
        ...done,
        route: action.next ?? done.route,
        result: action.result,
        sessionOutdated: done.sessionOutdated || action.outdatesSession,
      };
  }
}

/** 받은 세션에 맞는 결과만 남긴다(다른 세션이거나 결과가 없어졌으면 버린다). */
function matchingResult(result: ResultView | null, session: SessionView): ResultView | null {
  return result !== null && result.session_id === session.session_id && session.has_result ? result : null;
}
```

```ts
import { sessionIdOf, taskOf } from "../lib/routes";
import type { AppState } from "./state";

/** 화면을 그리는 데 모자란 데이터 하나. */
export type Load =
  | { kind: "tasks" }
  | { kind: "form"; task: string }
  | { kind: "session"; sessionId: string }
  | { kind: "result"; sessionId: string };

export function loadKey(load: Load): string {
  switch (load.kind) {
    case "tasks":
      return "tasks";
    case "form":
      return `form:${load.task}`;
    default:
      return `${load.kind}:${load.sessionId}`;
  }
}

/** [순수] 지금 불러올 데이터. 요청을 기다리는 중이거나 같은 불러오기가 이 화면에서 실패했으면 부르지 않는다. */
export function needsLoad(state: AppState): Load | null {
  if (state.inflight !== null) return null;
  const load = missing(state);
  return load !== null && loadKey(load) !== state.stalled ? load : null;
}

function missing(state: AppState): Load | null {
  if (state.tasks.length === 0) return { kind: "tasks" };
  const task = taskOf(state.route);
  if (task !== null) return state.form?.task_type === task ? null : { kind: "form", task };
  const sessionId = sessionIdOf(state.route);
  if (sessionId === null) return null;
  const session = state.session;
  if (session === null || session.session_id !== sessionId || state.sessionOutdated) {
    return { kind: "session", sessionId };
  }
  const wantsResult = state.route.name === "result" && session.has_result;
  return wantsResult && state.result?.session_id !== sessionId ? { kind: "result", sessionId } : null;
}
```

```ts
import type { Question, ResultView, SessionView, TaskForm, TaskSummary } from "../api/types";
import { isEditable } from "../lib/flowView";
import type { EditableFlowItem } from "../lib/flowView";
import type { AppState } from "./state";

/** 지금 그릴 화면과 그 화면에 필요한 값. 화면은 이 값만 보고 그린다. */
export type ScreenModel =
  | { kind: "loading" }
  | { kind: "unavailable" }
  | { kind: "home"; tasks: TaskSummary[] }
  | { kind: "guide" }
  | { kind: "request"; task: TaskSummary; form: TaskForm; draft: string }
  | { kind: "mode"; task: TaskSummary; form: TaskForm; draft: string }
  | { kind: "question"; task: TaskSummary; session: SessionView; question: Question }
  | { kind: "revise"; task: TaskSummary; session: SessionView; item: EditableFlowItem }
  | { kind: "confirm"; task: TaskSummary; session: SessionView }
  | { kind: "result"; task: TaskSummary; session: SessionView; result: ResultView | null };

const LOADING: ScreenModel = { kind: "loading" };

/** [순수] 지금 그릴 화면. 데이터가 모자라면 loading, 불러오기가 실패했으면 unavailable이다. */
export function screenModel(state: AppState): ScreenModel {
  const model = resolve(state);
  return model.kind === "loading" && state.stalled !== null ? { kind: "unavailable" } : model;
}

function resolve(state: AppState): ScreenModel {
  const { route } = state;
  switch (route.name) {
    case "home":
      return state.tasks.length === 0 ? LOADING : { kind: "home", tasks: state.tasks };
    case "guide":
      return { kind: "guide" };
    case "request":
    case "mode": {
      const task = findTask(state.tasks, route.task);
      if (task === null || state.form === null || state.form.task_type !== route.task) return LOADING;
      const data = { task, form: state.form, draft: state.drafts[route.task] ?? "" };
      return route.name === "request" ? { kind: "request", ...data } : { kind: "mode", ...data };
    }
    default: {
      const session = state.session;
      if (session === null || session.session_id !== route.sessionId) return LOADING;
      const task = findTask(state.tasks, session.task_type);
      if (task === null) return LOADING;
      if (route.name === "result") {
        const result = state.result !== null && state.result.session_id === session.session_id ? state.result : null;
        return { kind: "result", task, session, result };
      }
      if (route.name === "revise") {
        const item = session.flow.find((i) => i.question?.question_id === route.questionId);
        if (item !== undefined && isEditable(item)) return { kind: "revise", task, session, item };
      }
      if (route.name !== "confirm" && session.next_question !== null) {
        return { kind: "question", task, session, question: session.next_question };
      }
      return { kind: "confirm", task, session };
    }
  }
}

function findTask(tasks: TaskSummary[], taskType: string): TaskSummary | null {
  return tasks.find((t) => t.task_type === taskType) ?? null;
}
```

```ts
import type { FlowItem, FlowStatus, Question } from "../api/types";

/** 답을 고칠 수 있는 흐름 항목: 답했거나 미정으로 둔 질문(그 질문이 실려 있다). */
export type EditableFlowItem = FlowItem & { question: Question };

export function isEditable(item: FlowItem): item is EditableFlowItem {
  return item.question !== null && (item.status === "answered" || item.status === "skipped");
}

const STATUS_LABEL: Record<FlowStatus, string> = {
  answered: "완료",
  current: "현재 질문",
  upcoming: "예정",
  skipped: "아직 미정",
};

export function flowStatusLabel(status: FlowStatus): string {
  return STATUS_LABEL[status];
}

/** 흐름 패널 번호. 01은 요청 정리라 질문은 02부터다. */
export function flowNumber(index: number): string {
  return String(index + 2).padStart(2, "0");
}

/** 항목 아래 한 줄: 정한 답이나 지금 상태. */
export function flowNote(item: FlowItem): string {
  switch (item.status) {
    case "answered":
      return item.answer ?? "";
    case "skipped":
      return "아직 미정으로 남겨 뒀어요.";
    case "current":
      return "답변을 기다리고 있어요.";
    case "upcoming":
      return "차례가 오면 물어볼게요.";
  }
}

/** '← 이전 단계'로 고칠 질문: 지금 질문 바로 앞(지금 질문이 없으면 마지막)의 답한·미정 항목. */
export function previousEditable(flow: FlowItem[]): string | null {
  const current = flow.findIndex((item) => item.status === "current");
  const before = current === -1 ? flow : flow.slice(0, current);
  const item = [...before].reverse().find(isEditable);
  return item ? item.question.question_id : null;
}

/** '답변 바꾸기'로 고칠 첫 질문. */
export function firstEditable(flow: FlowItem[]): string | null {
  const item = flow.find(isEditable);
  return item ? item.question.question_id : null;
}

/** 진행 표시. 물어본(답한·미정) 질문과 지금 질문을 세고, 지금 질문이 없으면 마쳤다고 붙인다. */
export function questionPosition(flow: FlowItem[], cap: number): string {
  const shown = Math.min(flow.filter((item) => item.status !== "upcoming").length, cap);
  return flow.some((item) => item.status === "current") ? `질문 ${shown}/${cap}` : `질문 ${shown}/${cap} · 마침`;
}
```

```ts
import type { SessionView } from "../api/types";

export type ResultAction = { action: "generate" | "show_result"; label: string; primary: boolean };

export const STALE_NOTICE = "답이 바뀌어 결과가 최신이 아니에요. 바뀐 답을 반영하려면 초안을 다시 만들어 주세요.";

/** [순수] 답변 확인 화면의 결과 버튼. 최신 결과가 있으면 다시 만들기(LLM 호출)보다 보기가 먼저다. */
export function confirmActions(session: Pick<SessionView, "has_result" | "result_stale">): ResultAction[] {
  if (!session.has_result) return [{ action: "generate", label: "맞아요 · 이 정보로 초안 만들기", primary: true }];
  if (session.result_stale) {
    return [
      { action: "generate", label: "바뀐 답으로 초안 다시 만들기", primary: true },
      { action: "show_result", label: "이전 결과 보기", primary: false },
    ];
  }
  return [
    { action: "show_result", label: "결과 보기", primary: true },
    { action: "generate", label: "초안 다시 만들기", primary: false },
  ];
}

/** [순수] 결과 화면의 다시 만들기. 결과가 낡았을 때만 주 버튼이다. */
export function regenerateAction(stale: boolean): ResultAction {
  return stale
    ? { action: "generate", label: "바뀐 답으로 다시 만들기", primary: true }
    : { action: "generate", label: "초안 다시 만들기", primary: false };
}

/** [순수] 버튼 이름과 막힘. 결과 보기는 LLM을 부르지 않으므로 생성 가능 여부와 상관없다. */
export function actionState(
  action: ResultAction,
  busy: boolean,
  canGenerate: boolean,
): { label: string; disabled: boolean } {
  const calls = action.action === "generate";
  return { label: busy && calls ? "초안을 만드는 중…" : action.label, disabled: busy || (calls && !canGenerate) };
}
```

```tsx
  busy: boolean;
```

```tsx
};

/** 선택지. 하나만 고르는 질문은 누르는 즉시 보내고, 여러 개 고르는 질문은 고른 뒤 한 번에 보낸다. */
export function OptionList({ question, busy, onChoose }: Props) {
  const [selected, setSelected] = useState<string[]>([]);
  if (question.options.length === 0) return null;
  const multi = question.multi_select;
  return (
    <>
      <div className="options" role="group" aria-label={multi ? "답 고르기 · 여러 개 고를 수 있어요" : "답 고르기"}>
        {question.options.map((option) => (
          <button
            key={option.id}
            type="button"
            className="btn full choice"
            aria-pressed={multi ? selected.includes(option.id) : undefined}
            disabled={busy}
            onClick={() => (multi ? setSelected((prev) => toggleSelection(prev, option.id, true)) : onChoose([option.id]))}
          >
            {option.label}
            {option.ai_suggested && <span className="badge">AI 제안</span>}
          </button>
        ))}
      </div>
      {multi && (
        <button type="button" className="btn primary" disabled={busy || selected.length === 0} onClick={() => onChoose(selected)}>
          고른 답 보내기
        </button>
      )}
    </>
  );
```

```tsx
    return (
```

```tsx
        <h1>아직 만든 결과가 없어요</h1>

  return (

      result={result}
      title={resultTitle(task.title)}
      kicker={resultKicker(task.deliverable, session.result_stale)}
      rows={criteriaRows(session.summary, session.unknowns)}

  );
}

type SideProps = {

  busy: boolean;
  onRegenerate: () => void;
```

```tsx
export type Handlers = {
  navigate: (key: NavKey) => void;
  guide: () => void;
  goHome: () => void;
  retry: () => void;
  start: (task: string) => void;
  changeDraft: (task: string, text: string) => void;
  submitRequest: (task: string) => void;
  editRequest: (task: string) => void;
  pickMode: (task: string, mode: CoachingMode) => void;
  answer: (body: AnswerBody) => void;
  example: (action: ExampleAction["action"]) => void;
  earlyDraft: () => void;
  edit: (questionId: string) => void;
  revise: (questionId: string, body: ReviseBody) => void;
  backToQuestions: () => void;
  generate: () => void;
  showResult: () => void;
  confirm: () => void;
  continueQuestions: () => void;
};

export type ScreenParts = { main: JSX.Element; side: JSX.Element | null };

/** 화면 모델 → 본문과 오른쪽 패널. 판단은 하지 않고 모델과 lib의 순수 함수로만 그린다. */
export function renderScreen(model: ScreenModel, busy: boolean, on: Handlers): ScreenParts {
  switch (model.kind) {
    case "loading":
      return { main: <LoadingScreen />, side: null };
    case "unavailable":
      return { main: <UnavailableScreen onRetry={on.retry} onHome={on.goHome} />, side: null };
    case "home":
      return { main: <HomeScreen tasks={model.tasks} onStart={on.start} />, side: null };
    case "guide":
      return { main: <GuideScreen onStart={on.goHome} />, side: null };
    case "request": {
      const task = model.task.task_type;
      return {
        main: (
          <RequestScreen
            task={model.task}
            form={model.form}
            draft={model.draft}
            onChange={(text) => on.changeDraft(task, text)}
            onSubmit={() => on.submitRequest(task)}
          />
        ),
        side: null,
      };
    }
    case "mode": {
      const task = model.task.task_type;
      return {
        main: (
          <ModeScreen
            form={model.form}
            draft={model.draft}
            busy={busy}
            onPick={(mode) => on.pickMode(task, mode)}
            onEditRequest={() => on.editRequest(task)}
          />
        ),
        side: null,
      };
    }
    case "question":
      return {
        main: (
          <QuestionCard
            key={model.question.question_id}
            question={model.question}
            kicker={questionKicker(model.question, model.session.progress.asked)}
            request={model.session.raw_input}
            busy={busy}
            onAnswer={on.answer}
            onExample={on.example}
            onEarlyDraft={on.earlyDraft}
          />
        ),
        side: flowSide(model.session, false, busy, on),
      };
    case "revise": {
      const questionId = model.item.question.question_id;
      return {
        main: (
          <ReviseCard
            key={questionId}
            item={model.item}
            busy={busy}
            onRevise={(body) => on.revise(questionId, body)}
            onCancel={on.backToQuestions}
          />
        ),
        side: flowSide(model.session, false, busy, on),
      };
    }
    case "confirm": {
      const editable = firstEditable(model.session.flow);
      return {
        main: (
          <ConfirmScreen
            task={model.task}
            session={model.session}
            busy={busy}
            onAct={(action) => (action === "generate" ? on.generate() : on.showResult())}
            onChangeAnswers={editable ? () => on.edit(editable) : null}
            onBackToQuestion={model.session.next_question ? on.backToQuestions : null}
          />
        ),
        side: flowSide(model.session, true, busy, on),
      };
    }
    case "result": {
      const editable = firstEditable(model.session.flow);
      return {
        main: <ResultMain task={model.task} session={model.session} result={model.result} busy={busy} onConfirm={on.confirm} />,
        side:
          model.result === null ? null : (
            <ResultSide
              session={model.session}
              busy={busy}
              onRegenerate={on.generate}
              onChangeAnswers={editable ? () => on.edit(editable) : null}
              onContinue={on.continueQuestions}
            />
          ),
      };
    }
  }
}

function flowSide(session: SessionView, atConfirm: boolean, busy: boolean, on: Handlers): JSX.Element {
  const previous = previousEditable(session.flow);
  return (
    <FlowPanel
      modeLabel={modeName(session.mode)}
      position={questionPosition(session.flow, session.progress.cap)}
      request={session.raw_input}
      flow={session.flow}
      atConfirm={atConfirm}
      busy={busy}
      onEdit={on.edit}
      onPrevious={previous ? () => on.edit(previous) : null}
    />
  );
}

/** 헤더의 과제 이름. 과제 밖 화면은 null이다. */
export function projectOf(model: ScreenModel): string | null {
  return "task" in model ? model.task.title : null;
}

export function pageTitle(model: ScreenModel): string {
  const project = projectOf(model);
  return project ? `창작자 AX · ${project}` : "창작자 AX";
}

type ViewProps = { route: Route; model: ScreenModel; busy: boolean; on: Handlers; mainId?: string };

/** 뼈대까지 그린 화면 하나. 앱과 미리보기 갤러리가 같이 쓴다(갤러리는 프레임마다 mainId를 바꾼다). */
export function AppView({ route, model, busy, on, mainId }: ViewProps) {
  const { main, side } = renderScreen(model, busy, on);
  return (
    <AppShell
      rail={{
        items: railItems(railActive(route), enabledNav(busy)),
        onNavigate: on.navigate,
        onGuide: on.guide,
        guideDisabled: busy,
      }}
      header={{ project: projectOf(model), phase: routePhase(route), onPickTask: on.goHome, pickDisabled: busy }}
      side={side}
      mainId={mainId}
    >
      {main}
    </AppShell>
  );
}
```

```ts
import { BACKEND_UNREACHABLE, toOutcome } from "../api/client";
import type { ApiResult } from "../api/client";
import { getResult, getSession, getTaskForm, listTasks } from "../api/coaching";
import { loadKey } from "./load";
import type { Load } from "./load";
import type { Action } from "./state";

/** 요청 하나. done은 성공한 응답을 상태 변경(Action)으로 바꾼다. */
export type Call<T> = {
  request: () => Promise<ApiResult<T>>;
  done: (data: T, seq: number) => Action;
  load: string | null; // 화면을 그리려고 부르는 요청이면 그 이름(loadKey). 실패하면 같은 화면에서 다시 부르지 않는다
  outdatesSessionOnFail: boolean; // 실패해도 서버 세션이 바뀌었을 수 있으면(생성 실패 → FAILED) true
};

export type Runner = <T>(call: Call<T>) => Promise<void>;

/** 요청마다 번호를 붙여 시작과 끝을 알린다. 번호가 다른(늦게 온) 응답은 리듀서가 버린다. */
export function createRunner(dispatch: (action: Action) => void): Runner {
  let seq = 0;
  return async <T>({ request, done, load, outdatesSessionOnFail }: Call<T>) => {
    seq += 1;
    const mine = seq;
    dispatch({ type: "requested", seq: mine, load });
    try {
      const outcome = toOutcome(await request());
      dispatch(
        outcome.ok
          ? done(outcome.data, mine)
          : { type: "failed", seq: mine, message: outcome.message, outdatesSession: outdatesSessionOnFail },
      );
    } catch {
      dispatch({ type: "failed", seq: mine, message: BACKEND_UNREACHABLE, outdatesSession: false });
    }
  };
}

/** 화면에 모자란 데이터(needsLoad)를 부른다. */
export function startLoad(run: Runner, load: Load): Promise<void> {
  const key = loadKey(load);
  switch (load.kind) {
    case "tasks":
      return run({
        request: listTasks,
        done: (tasks, seq) => ({ type: "tasksLoaded", seq, tasks }),
        load: key,
        outdatesSessionOnFail: false,
      });
    case "form":
      return run({
        request: () => getTaskForm(load.task),
        done: (form, seq) => ({ type: "formLoaded", seq, form }),
        load: key,
        outdatesSessionOnFail: false,
      });
    case "session":
      return run({
        request: () => getSession(load.sessionId),
        done: (session, seq) => ({ type: "sessionLoaded", seq, session, next: null, notice: null }),
        load: key,
        outdatesSessionOnFail: false,
      });
    case "result":
      return run({
        request: () => getResult(load.sessionId),
        done: (result, seq) => ({ type: "resultLoaded", seq, result, next: null, outdatesSession: false }),
        load: key,
        outdatesSessionOnFail: false,
      });
  }
}
```

```ts
import type { ApiResult } from "../api/client";
import {
  continueSession,
  createSession,
  generateResult,
  reviseAnswer,
  showOriginalQuestion,
  submitAnswer,
} from "../api/coaching";
import type { AnswerBody, SessionView } from "../api/types";
import { HOME } from "../lib/routes";
import type { Route } from "../lib/routes";
import type { Runner } from "./requests";
import type { Action, AppState } from "./state";
import type { Handlers } from "./view";

export const NOTHING_LEFT_NOTICE = "더 물어볼 질문이 없어요.";

/** [순수] 답이 바뀐 세션의 다음 화면. 걸린 질문이 있으면 질문, 없으면 답변 확인. */
export function routeAfterSession(session: SessionView): Route {
  return session.next_question
    ? { name: "question", sessionId: session.session_id }
    : { name: "confirm", sessionId: session.session_id };
}

type Deps = {
  state: Pick<AppState, "session" | "drafts">;
  run: Runner;
  dispatch: (action: Action) => void;
  saveDraft: (task: string, text: string) => void;
};

/** 화면 버튼 → 화면 이동(dispatch) 또는 API 요청(run). 상태는 리듀서만 바꾼다. */
export function makeHandlers({ state, run, dispatch, saveDraft }: Deps): Handlers {
  const session = state.session;
  const go = (route: Route) => dispatch({ type: "navigated", route });

  /** 세션을 바꾸는 요청. 응답 세션의 다음 화면(질문 또는 답변 확인)으로 간다. */
  const moveOn = (request: () => Promise<ApiResult<SessionView>>) =>
    void run({
      request,
      done: (next, seq) => ({ type: "sessionLoaded", seq, session: next, next: routeAfterSession(next), notice: null }),
      load: null,
      outdatesSessionOnFail: false,
    });

  const answer = (body: AnswerBody) => {
    const question = session?.next_question;
    if (session && question) moveOn(() => submitAnswer(session.session_id, question.question_id, body));
  };

  return {
    navigate: (key) => {
      if (key === "home") go(HOME);
    },
    guide: () => go({ name: "guide" }),
    goHome: () => go(HOME),
    retry: () => dispatch({ type: "retried" }),
    start: (task) => go({ name: "request", task }),
    changeDraft: (task, text) => {
      dispatch({ type: "draftChanged", task, text });
      saveDraft(task, text);
    },
    submitRequest: (task) => go({ name: "mode", task }),
    editRequest: (task) => go({ name: "request", task }),
    pickMode: (task, mode) => moveOn(() => createSession(task, state.drafts[task] ?? "", mode)),
    answer,
    example: (action) => {
      if (action === "easier") answer({ answer_type: "easier" });
      else if (session) moveOn(() => showOriginalQuestion(session.session_id));
    },
    earlyDraft: () => {
      if (session) go({ name: "confirm", sessionId: session.session_id });
    },
    edit: (questionId) => {
      if (session) go({ name: "revise", sessionId: session.session_id, questionId });
    },
    revise: (questionId, body) => {
      if (session) moveOn(() => reviseAnswer(session.session_id, questionId, body));
    },
    backToQuestions: () => {
      if (session) go(routeAfterSession(session));
    },
    generate: () => {
      if (!session) return;
      const sessionId = session.session_id;
      void run({
        request: () => generateResult(sessionId),
        done: (result, seq) => ({
          type: "resultLoaded",
          seq,
          result,
          next: { name: "result", sessionId },
          outdatesSession: true,
        }),
        load: null,
        outdatesSessionOnFail: true,
      });
    },
    showResult: () => {
      if (session) go({ name: "result", sessionId: session.session_id });
    },
    confirm: () => {
      if (session) go({ name: "confirm", sessionId: session.session_id });
    },
    continueQuestions: () => {
      if (!session) return;
      void run({
        request: () => continueSession(session.session_id),
        done: (next, seq) => ({
          type: "sessionLoaded",
          seq,
          session: next,
          next: next.next_question ? routeAfterSession(next) : null,
          notice: next.next_question ? null : NOTHING_LEFT_NOTICE,
        }),
        load: null,
        outdatesSessionOnFail: false,
      });
    },
  };
}
```

```tsx
import { useEffect, useMemo, useReducer } from "react";

import { Toast } from "../components/Toast";
import { readDraft, writeDraft } from "../lib/drafts";
import { parseRoute, taskOf, toHash } from "../lib/routes";
import { browserStorage } from "../lib/storage";
import { makeHandlers } from "./handlers";
import { needsLoad } from "./load";
import { createRunner, startLoad } from "./requests";
import { screenModel } from "./screenModel";
import { initialState, isBusy, reducer } from "./state";
import { AppView, pageTitle } from "./view";

const TOAST_MS = 3500;

/** 앱 상태는 reducer 하나가 바꾼다. 여기서는 주소·불러오기·저장소·알림 같은 바깥과의 연결만 한다. */
export default function App() {
  const [state, dispatch] = useReducer(reducer, window.location.hash, (hash: string) => initialState(parseRoute(hash)));
  const run = useMemo(() => createRunner(dispatch), []);
  const storage = useMemo(browserStorage, []);

  // 주소 → 상태(뒤로 가기·직접 입력)
  useEffect(() => {
    const onHashChange = () => dispatch({ type: "navigated", route: parseRoute(window.location.hash) });
    window.addEventListener("hashchange", onHashChange);
    return () => window.removeEventListener("hashchange", onHashChange);
  }, []);

  // 상태 → 주소. 화면이 바뀌면 본문으로 초점을 옮기고 맨 위로 올린다.
  useEffect(() => {
    const hash = toHash(state.route);
    if (window.location.hash !== hash) window.location.hash = hash;
    document.getElementById("main")?.focus({ preventScroll: true });
    window.scrollTo(0, 0);
  }, [state.route]);

  // 화면에 모자란 데이터 불러오기
  useEffect(() => {
    const load = needsLoad(state);
    if (load) void startLoad(run, load);
  }, [state, run]);

  // 쓰다 만 요청 글은 과제 화면에 처음 들어올 때 저장소에서 꺼낸다
  const task = taskOf(state.route);
  useEffect(() => {
    if (task !== null && !(task in state.drafts)) {
      dispatch({ type: "draftChanged", task, text: readDraft(storage, task) });
    }
  }, [task, state.drafts, storage]);

  // 알림은 잠시 뒤 닫는다
  useEffect(() => {
    if (state.toast === null) return;
    const timer = window.setTimeout(() => dispatch({ type: "toastClosed" }), TOAST_MS);
    return () => window.clearTimeout(timer);
  }, [state.toast]);

  const model = screenModel(state);
  const title = pageTitle(model);
  useEffect(() => {
    document.title = title;
  }, [title]);

  const on = makeHandlers({ state, run, dispatch, saveDraft: (key, text) => writeDraft(storage, key, text) });
  return (
    <>
      <AppView route={state.route} model={model} busy={isBusy(state)} on={on} />
      <Toast message={state.toast} />
    </>
  );
}
```
