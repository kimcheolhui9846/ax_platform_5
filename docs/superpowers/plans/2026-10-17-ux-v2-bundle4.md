# 묶음 4: 다음 과제로 이어가기 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 저장한 결과에서 "이 결과로 ○○ 시작"을 누르면 다음 과제의 요청 화면이 이전 결과(제목·요약·가져올 항목)를 보여 주고, 세션을 만들 때 이전 결과의 사실·보완 정보를 새 과제 필드로 가져온다(출처 `previous_task`, 그 필드는 묻지 않는다). 가져온 내용은 세션 전에는 빼고 시작할 수 있고, 세션 뒤에는 `DELETE /sessions/{id}/context`로 뺀다.

**Architecture:** 가져오기 판단은 백엔드 순수 함수 하나(`build_context`)가 한다: 이전 세션의 한 버전(사실·보완 정보)과 새 과제 정책(필드, `carry_over`)으로 `CarriedContext`(제목·요약·항목)를 만든다. 미리보기 `GET /tasks/{task}/context`와 세션 만들기가 같은 함수를 쓴다. 세션은 `SessionState.context`에 가져온 내용을 두고, 하네스 `start`가 기본값 다음·진단 전에 사실로 넣는다(새 요청 글은 진단이 덮는다). 프론트는 출처를 주소(`#/{task}/request/from/{sid}/{v}`)에 실어 새로고침해도 남고, 미리보기는 불러오기(`Load` `carry`)로 받는다.

**Tech Stack:** FastAPI·Pydantic v2·Jinja2(백엔드), React 19·TypeScript·vitest(프론트).

## 결정 사항 (컨트롤러)

1. **가져오는 값**: 이전 세션의 고른 버전(기본은 마지막 버전)에 담긴 사실(`facts`)과 보완 정보(`supplements`). AI 가정·미정은 가져오지 않는다. 같은 이름이 둘 다 있으면 사실이 먼저다.
2. **필드 대응**: 새 과제 필드마다 후보는 [같은 이름, 그다음 `carry_over`에서 그 필드를 가리키는 이전 이름들(적은 순서)]이고, 이전 값에 있는 첫 후보를 쓴다. `carry_over`의 값(대상)은 이 정책의 필드여야 한다(읽을 때 검증). 키(이전 이름)는 다른 과제의 필드·보완 항목 이름이라 검증하지 않는다.
3. **새 요청 글이 이긴다**: 가져오기는 `apply_defaults` 다음, `diagnose` 전에 한다. `raw_input_field`는 진단이 새 요청 글로 덮는다. 기본값 필드는 가져온 값이 덮는다.
4. **요약**: 이전 결과의 첫 섹션 글을 공백 정리해 160자로 자른다(넘치면 `…`). 제목은 "{이전 과제 이름} 초안 V{n}".
5. **빼기**: `DELETE /sessions/{id}/context`는 가져온 항목 가운데 아직 출처가 `previous_task`인 사실만 지우고(사용자가 그 뒤 고친 값은 둔다) `context`를 비운다. 결과가 있으면 최신 여부를 `answers_changed`·`supplements_changed`로 다시 정하고 상태를 정리한다(`_settle_status`). 가져온 내용이 없으면 그대로 200.
6. **잘못된 출처**: 남의·없는 이전 세션은 404 `PREVIOUS_SESSION_NOT_FOUND_MESSAGE`, 그 버전이 없으면 404 `VERSION_NOT_FOUND_MESSAGE`. 같은 과제에서 이어 가기도 막지 않는다.
7. **프롬프트**: `_context.md`에 가져온 내용이 있을 때만 "## 이전 과제 결과" 블록(제목·요약). 가져온 사실은 이미 "확인된 사실"에 출처 "이전 과제"로 나온다.
8. **화면**: 저장 완료 화면에 "이 결과로 {다음 과제} 시작"(주 버튼)과 안내 문장. 요청·모드 화면에 "이전 작업에서 가져온 기준" 상자와 "가져온 내용 제외"(세션 전: 주소에서 출처를 뗀다). 답변 확인 화면에도 같은 상자(세션 뒤: `DELETE`). 결과 문서·내려받기는 바꾸지 않는다(가져온 사실이 기준 표에 "이전 과제"로 나온다).

```python
"""다음 과제로 이어가기. 이전 결과 버전의 사실·보완 정보를 새 과제 필드로 옮길 값을 정한다(모두 순수 함수)."""
import re
from collections.abc import Mapping, Sequence

from app.core.results import section_text
from app.core.state import CarriedContext, CarriedItem, InfoItem, ResultVersion, SessionState
from app.harness.policy import FieldPolicy, TaskPolicy

SUMMARY_LIMIT = 160


def carry_values(
    facts: Mapping[str, InfoItem],
    supplements: Mapping[str, InfoItem],
    fields: Sequence[FieldPolicy],
    carry_over: Mapping[str, str],
) -> list[CarriedItem]:
    """[순수] 새 과제 필드마다 가져올 값. 후보는 같은 이름, 그다음 carry_over에서 그 필드를 가리키는 이전 이름(적은 순서).

    사실이 보완 정보보다 먼저다. 값이 없는 필드는 빠진다.
    """
    values = {**{n: i.value for n, i in supplements.items()}, **{n: i.value for n, i in facts.items()}}
    items: list[CarriedItem] = []
    for f in fields:
        candidates = [f.name, *(src for src, dst in carry_over.items() if dst == f.name)]
        found = next((name for name in candidates if values.get(name, "").strip()), None)
        if found is not None:
            items.append(CarriedItem(field=f.name, value=values[found].strip(), from_name=found))
    return items


def summarize(text: str, limit: int = SUMMARY_LIMIT) -> str:
    """[순수] 공백을 하나로 줄이고 limit자를 넘으면 잘라 …을 붙인다."""
    flat = re.sub(r"\s+", " ", text).strip()
    return flat if len(flat) <= limit else flat[: limit - 1] + "…"


def build_context(source: SessionState, version: ResultVersion, source_title: str, target: TaskPolicy) -> CarriedContext:
    """[순수] 이전 세션의 그 버전으로 다음 과제에 가져올 기준(미리보기와 세션 만들기가 같이 쓴다)."""
    sections = sorted(version.result.sections, key=lambda s: s.order)
    return CarriedContext(
        session_id=source.session_id,
        task_type=source.task_type,
        version=version.version,
        title=f"{source_title} 초안 V{version.version}",
        summary=summarize(section_text(sections[0])) if sections else "",
        items=carry_values(version.facts, version.supplements, target.fields, target.carry_over),
    )
```

```python
    def clear_context(self, state: SessionState) -> None:
        """이전 과제에서 가져온 내용을 뺀다. 아직 출처가 previous_task인 사실만 지운다(그 뒤 사용자가 고친 값은 둔다).

        결과가 있으면 최신 여부를 답·보완 정보가 마지막 버전과 다른지로 다시 정하고 상태를 정리한다. 가져온 내용이 없으면
        그대로다.
        """
        if state.context is None:
            return
        for item in state.context.items:
            current = state.facts.get(item.field)
            if current is not None and current.source is InfoSource.PREVIOUS_TASK:
                del state.facts[item.field]
```
