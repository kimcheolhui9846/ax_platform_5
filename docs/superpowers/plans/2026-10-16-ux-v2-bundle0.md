# UX V2 묶음 0 — 토큰·앱 뼈대·미리보기 갤러리·버셀 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 디자인 V2의 토큰과 앱 뼈대를 프론트에 깐다. 뼈대는 왼쪽 메뉴, 헤더, 본문, 오른쪽 패널로 이뤄진다. 그 위에 모든 화면 상태를 백엔드 없이 보여 주는 미리보기 갤러리(`/preview`)를 만들고, 버셀에 배포할 준비를 한다.

**Architecture:**
- 원시 디자인 값(색·크기·간격)은 `src/styles/tokens.css`에만 둔다. 다른 CSS는 `var(--…)`만 쓴다.
- 앱 뼈대는 props만 받는 `layout/` 컴포넌트다. 판단은 `lib/shell.ts`의 순수 함수가 한다.
- 갤러리는 앱과 같은 컴포넌트를 샘플 데이터(`preview/fixtures.ts`, 생성된 API 타입 사용)로 그린다.
- API 주소는 `VITE_API_BASE`로 바꿀 수 있다. 백엔드에 연결하지 못하면 앱이 안내 문구를 띄운다.

**Tech Stack:** React 19, Vite 8 (멀티 페이지 빌드), TypeScript 5.9, vitest 5, `react-dom/server`의 `renderToString`, 버셀.

**Spec:** `docs/superpowers/specs/2026-10-16-ux-v2-design.md`의 4장, 5장, 6장 묶음 0.

```ts
import { describe, expect, it } from "vitest";

// Vite가 빌드 시점에 CSS 원문을 문자열로 넣어 준다(node 타입 없이 동작).
const sheets = import.meta.glob("./*.css", { query: "?raw", import: "default", eager: true }) as Record<string, string>;

const RAW_COLOR = /#[0-9a-fA-F]{3,8}\b|rgba?\(|hsla?\(/;

function definedVars(css: string): Set<string> {
  return new Set([...css.matchAll(/(--[a-z0-9-]+)\s*:/g)].map((m) => m[1]));
}

function usedVars(css: string): string[] {
  return [...css.matchAll(/var\((--[a-z0-9-]+)/g)].map((m) => m[1]);
}

describe("디자인 토큰", () => {
  it("tokens.css가 있다", () => {
    expect(Object.keys(sheets)).toContain("./tokens.css");
  });

  it("원시 색상은 tokens.css에만 있다", () => {
    const offenders = Object.entries(sheets)
      .filter(([name]) => name !== "./tokens.css")
      .filter(([, css]) => RAW_COLOR.test(css))
      .map(([name]) => name);
    expect(offenders).toEqual([]);
  });

  it("쓰는 변수는 모두 tokens.css에 정의돼 있다", () => {
    const defined = definedVars(sheets["./tokens.css"] ?? "");
    const missing = Object.values(sheets)
      .flatMap(usedVars)
      .filter((name) => !defined.has(name));
    expect([...new Set(missing)]).toEqual([]);
  });
});
```

```ts
import type { screenOf } from "./screen";

export type NavKey = "home" | "work" | "documents";
export type Phase = 0 | 1 | 2;
export type ScreenKind = ReturnType<typeof screenOf>["kind"];
export type RailItem = { key: NavKey; label: string; active: boolean; disabled: boolean };

export const HEADER_STEPS = ["내 요청", "함께 구체화", "결과 만들기"] as const;

const NAV_LABELS: Record<NavKey, string> = { home: "홈", work: "내 작업", documents: "결과물" };
const NAV_ORDER: readonly NavKey[] = ["home", "work", "documents"];

/** 헤더의 3단계 표시. 과제 밖(null)에서는 단계를 보여 주지 않는다. */
export function headerSteps(phase: Phase | null): { label: string; current: boolean }[] {
  if (phase === null) return [];
  return HEADER_STEPS.map((label, i) => ({ label, current: i === phase }));
}

/** 화면 종류가 헤더의 몇 번째 단계인지. 과제를 고르기 전에는 과제 밖이다. */
export function phaseOf(kind: ScreenKind): Phase | null {
  if (kind === "pick_task") return null;
  if (kind === "idea") return 0;
  if (kind === "result") return 2;
  return 1;
}

/** 왼쪽 메뉴 항목. enabled에 없는 항목은 아직 만들지 않은 화면이라 막아 둔다. */
export function railItems(active: NavKey | null, enabled: ReadonlySet<NavKey>): RailItem[] {
  return NAV_ORDER.map((key) => ({
    key,
    label: NAV_LABELS[key],
    active: key === active,
    disabled: !enabled.has(key),
  }));
}
```

/** API 주소. 버셀에서 백엔드(렌더)를 따로 둘 때 VITE_API_BASE로 바꾼다. 비어 있으면 같은 출처다. */
export function apiBaseUrl(env: string | undefined): string {
