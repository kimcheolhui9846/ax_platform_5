# 시연 시나리오 (Mock, 비용 0)

발표·인수 설명에서 앱을 보여 주는 순서다. AI 응답은 Mock이라 질문·결과 글에 `[mock]`이 붙는다. **질문 흐름·화면·상태 변화는 실제와 같고, 바뀌는 것은 AI가 쓰는 글뿐**이라고 먼저 말해 둔다.

- 앱: https://ax-platform-5.vercel.app · 화면 갤러리: https://ax-platform-5.vercel.app/preview
- 걸리는 시간: 핵심 흐름 7분, 전체 12분

## 시연 전 확인 (10분 전)

| 확인 | 왜 |
|---|---|
| 앱을 열어 홈이 뜨는지 | 렌더 무료 서버는 15분 동안 요청이 없으면 잠들고 깨는 데 1분쯤 걸린다. "백엔드가 연결되어 있지 않습니다"가 보이면 1분 뒤 새로고침 |
| 새 시크릿 창 | 이전 시연의 세션·확인 기록이 섞이지 않게(익명 ID는 브라우저마다 다르다) |
| 모바일 화면(개발자 도구 390px 또는 휴대폰) | 모바일 우선 설계를 보여 준다. 배치가 바뀌는 것도 한 번 보여 준다 |
| `/preview` 탭 하나 더 | 서버가 안 깨어나면 갤러리로 모든 화면을 대신 보여 준다(백엔드 없이 열린다) |

서버가 다시 시작되면 저장한 세션이 지워진다. 보여 줄 결과는 시연 중에 새로 만든다.

## 핵심 흐름 (7분) — "프롬프트를 못 써도 결과물까지"

| # | 화면에서 할 일 | 보여 줄 점(말할 것) |
|---|---|---|
| 1 | 홈에서 **상품기획** 카드 | 과제 4개가 각자 다른 하네스(정책·질문·검증)를 가진다 |
| 2 | 요청 칸에 "집들이 선물용 수제 향초" 한 줄, 외부 전송 안내의 **확인했어요** | 긴 프롬프트가 필요 없다. 외부 AI로 보내기 전에 고지·동의를 받는다 |
| 3 | 모드에서 **스탠다드** | 빠른·스탠다드·정밀은 질문 수 상한이 다르다 |
| 4 | 첫 질문에서 선택지 하나 고르기 | 질문은 한 번에 하나, 선택지는 제안일 뿐 직접 입력도 된다 |
| 5 | 다음 질문에서 **다른 예시 보기** → 쉬운 질문 → **원래 예시 보기** | 어려운 질문은 한 단계씩 쉽게 바꿔 묻는다(사다리) |
| 6 | 다음 질문에서 **아직 모르겠어요** | 모르는 것은 미정으로 남기고 지어내지 않는다 |
| 7 | 오른쪽(모바일은 아래) 흐름 패널 | 물어본 것·지금 질문·남은 질문이 보인다. 답한 항목은 눌러서 고칠 수 있다 |
| 8 | 답변 확인 → **맞아요 · 이 정보로 초안 만들기** | 언제든 지금 정보로 만들 수 있다 |
| 9 | 생성 중 화면 → 결과 | 결과는 섹션 문서. '반영한 기준'에서 사실·AI 가정·미정이 출처와 함께 나뉜다 |
| 10 | 결과에서 **현재 버전 저장**(근거를 반영했으면 **출처와 함께 저장**) → 저장 완료 → **결과물 목록 보기** | 결과는 버전으로 쌓이고 저장한 버전을 다시 연다 |

## 더 보여 줄 것 (5분, 시간이 되면)

| 기능 | 하는 법 | 보여 줄 점 |
|---|---|---|
| 문구 수정 | 결과 섹션의 **문구 수정** → 고쳐서 반영 | AI를 다시 부르지 않고 새 버전(edit)이 생긴다 |
| 미확인 정보 채우기 | **미확인 정보 채우기**에 값 입력·저장 → 결과가 최신이 아님 배너 → **바뀐 내용으로 다시 만들기** | 사용자 보완 정보는 "검증 전"으로 따로 표시된다 |
| 근거 검토 | 상품기획 결과에서 근거 검토 → 자료 하나 반영 | 출처가 붙은 점검 문구가 결과에 들어간다(지금은 샘플 자료 2건) |
| 비공개 답 | 질문에서 **🔒 이 답은 AI에 보내지 않기** | 그 값은 AI 프롬프트에 가려져 나간다. 기준 표에 'AI에 보내지 않음' |
| 다음 과제로 이어가기 | 저장 완료 화면의 **이 결과로 브랜딩 시작** | 이전 결과의 기준을 가져와 같은 걸 다시 묻지 않는다. 가져온 내용은 뺄 수도 있다 |
| 참고 이미지 | 브랜딩 결과의 이미지 상자 | 이미지 자리(지금은 회색 자리표시) |
| 내려받기 | **문서 내려받기** | HTML 한 파일로 보관(서버가 다시 시작돼도 남는다) |
| 실패 처리 | `/preview`의 생성 실패·결과가 최신이 아님 프레임 | 실패해도 입력은 그대로 남고 다시 시도할 수 있다 |
